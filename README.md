# Массажный салон «Лавелия» — Алматы

Готовый редактируемый многостраничный сайт: 13 страниц, отдельная страница 404, мобильная навигация, выбор услуги, окно записи с переходом в WhatsApp, телефон и кнопка выбора маршрута в Яндекс Картах или 2ГИС. Для рабочего сайта с админкой подготовлены Cloudflare Workers и D1, код можно подключить через GitHub. Отдельный VPS или PHP-хостинг не требуется. Статический просмотр доступен отдельно.

## Админка и Cloudflare

Локальная админка: `http://localhost:4174/admin/`. Она изменяет цены, телефон, адрес и точку маршрута в локальной D1. На этой же версии сайта (`http://localhost:4174/`) изменения отражаются на всех страницах и в SEO-данных. Инструкции запуска и подключения облака: [CLOUDFLARE.md](CLOUDFLARE.md).

Публичный просмотр GitHub Pages не получает сохранения из локальной D1. Публикация рабочей админки в Cloudflare ещё не выполнена.

## Предварительный просмотр

Код хранится в репозитории `SWValera/massazhny-salon`. Рабочая ветка — `codex/laveliya-site`. Домен пока не подключён. HTML находится в `dist/`, исходники — в этой папке. Временная ссылка для телефона создаётся Cloudflare Quick Tunnel и доступна любому, кто знает ссылку. Она работает, пока компьютер не спит и запущены сервер и туннель. После перезапуска туннеля ссылка меняется.

Публичный просмотр: https://swvalera.github.io/massazhny-salon/

GitHub Actions автоматически обновляет его после изменений в `codex/laveliya-site`. Этот просмотр статический, без рабочего входа в админку и без сохранения в D1. Для рабочего сайта с админкой нужен отдельный деплой Cloudflare по инструкции ниже.

На этом компьютере: http://localhost:4173/

Для локального просмотра с телефона используйте адрес компьютера в той же Wi-Fi сети и порт 4173.

После остановки текущего просмотра запустите двойным щелчком `Просмотр сайта.command` либо выполните:

```sh
python3 scripts/preview.py
```

Терминал покажет новую ссылку `https://…trycloudflare.com`. Оставьте окно открытым. `Ctrl+C` завершит просмотр. Если порт занят, уже запущенный просмотр нужно сначала остановить.

Туннель передаёт только папку готового сайта `dist/`, не исходники и не другие файлы компьютера. Черновик закрыт от поисковиков через `noindex`, `robots.txt` и HTTP-заголовок. Это не парольная защита.

## Редактирование

- `scripts/build.py` — тексты, структура и исходные значения для статического просмотра; `scripts/templates.py` — шаблоны для Worker. В рабочей версии цены и контакты берутся из D1.
- `cloudflare/worker.js` — авторизация, сохранение и выдача страниц; `cloudflare/render.js` — валидация и подстановка данных.
- `admin/` — интерфейс администратора; `migrations/` — схема D1 и начальные значения.
- `assets/site.css` — сетка и адаптация для телефона; `assets/brand.css` — палитра #C8BED8 / #F4B5CD / #FCFAFD и оформление всех блоков.
- `assets/site.js` — меню, окно записи, выбор услуги, выбор карт и кнопка «Назад».
- `assets/` — локальные изображения и шрифты.

После правок:

```sh
python3 scripts/build.py
python3 scripts/check.py
```

Обновите страницу в браузере. Повторно запускать сервер и туннель не нужно.

Запись не имитирует отправку заявки: посетитель выбирает услугу, открывает WhatsApp и сам отправляет сообщение мастеру. Дата и стоимость подтверждаются лично. Сайт не хранит персональные данные и не использует аналитику. Встроенной карты нет: внешние карты открываются только по выбору посетителя.

## SEO и окончательный запуск

Все страницы содержат готовый HTML, уникальные title/description, один H1, внутренние ссылки, alt у изображений, семантические разделы и JSON-LD для местного бизнеса. Страницы массажа дополнительно содержат разметку услуг. Шрифты загружаются локально в WOFF2, изображения имеют уменьшенные версии для телефона, нижние фотографии загружаются отложенно.

Когда будет выбран настоящий HTTPS-домен:

```sh
python3 scripts/build.py --production --site-url https://YOUR-DOMAIN
python3 scripts/check.py
```

Команда включит индексацию, создаст абсолютные canonical/og:url и `sitemap.xml` с фотографиями, добавит структурированные хлебные крошки, обновит `robots.txt`. Домен не зашит в исходники. Проверяйте production-сборку на обычном хостинге: `scripts/serve.py` всегда отдаёт noindex, потому что предназначен для черновиков.

Для GitHub Pages с собственным доменом или сайта в корне домена достаточно публиковать `dist/`. Для GitHub Pages в подпапке `/repository/` понадобится настройка базового пути: сейчас ссылки начинаются от корня `/`.

Перед публичным запуском желательно дополнить факты: график, этаж/кабинет и вход, длительность сеансов и точные цены по зонам, подтверждённые сведения о мастере. Дипломы, отзывы, стаж и медицинские обещания не выдуманы. На странице лечебного массажа указано, что процедура не заменяет консультацию врача.

После запуска: подтвердить сайт в Google Search Console и Яндекс Вебмастере, отправить sitemap, оформить/уточнить карточки бизнеса в Google, Яндекс Картах и 2ГИС. Техническая подготовка не гарантирует сроков индексации или позиций в поиске.

## Изображения и источники

13 разных изображений созданы встроенным ImageGen специально для этого сайта. Фотографии не повторяются в видимом содержимом страниц; проверка сравнивает и пути, и содержимое файлов. Они иллюстративные: не показывают реального мастера или интерьер салона. Описания генерации находятся в `ASSETS-V2.md`. Сторонние фотографии салонов не использованы. Шрифты Manrope и Cormorant Garamond распространяются по SIL Open Font License; тексты лицензий сохранены рядом с файлами.

Координаты дома и маршрут проверены в [карточке 2ГИС](https://2gis.kz/almaty/geo/9430047374996996): 43.230853, 76.929838. Кнопка «Построить маршрут» раскрывает Яндекс Карты и 2ГИС. В обе ссылки передаётся конечная точка; начальная определяется картами при доступной геолокации или вводится посетителем. Формат 2ГИС описан в [официальной документации deeplink](https://help.2gis.ru/question/razrabotchikam-zapusk-ideystviya-vmobilnom-prilozhenii-cherez-deeplink). Временный просмотр использует [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
