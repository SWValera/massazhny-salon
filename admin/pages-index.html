Войдите с ключом GitHub, чтобы изменить цены и контакты салона. Ключ действует только в этой вкладке; после обновления страницы потребуется войти снова.

Как получить ключ для входа
  1. Войдите в аккаунт GitHub, которому принадлежит сайт.
  2. Откройте создание ключа доступа.
  3. В поле Token name укажите «Лавелия — админка» и выберите срок действия.
  4. В Repository access выберите Only select repositories → massazhny-salon.
  5. В Permissions добавьте Contents: Read and write. Другие права добавлять не нужно.
  6. Нажмите Generate token, скопируйте ключ и вставьте в поле выше. Сохраните его в менеджере паролей: GitHub показывает ключ один раз.

Это ключ доступа, а не пароль от GitHub. Админка отправляет его только GitHub для чтения и сохранения настроек.
