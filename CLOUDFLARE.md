# Лавелия: GitHub + Cloudflare Workers + D1

Код, страницы и оформление хранятся в GitHub. Cloudflare Workers отдаёт сайт и обслуживает защищённую админку `/admin/`. D1 хранит одну запись с ценами и контактами, версии настроек, сессии администратора и краткоживущие счётчики входа. Заявки и данные посетителей сайт не собирает. Изменение настроек не требует коммита или пересборки.

## Локальная проверка

```sh
npm ci
npm run build
npm run db:local
npm run dev
```

Сайт: `http://localhost:4174/`, админка: `http://localhost:4174/admin/`.
Локальная D1 сохраняется в игнорируемой папке `.wrangler/`. Старый просмотр на порту 4173 остаётся статическим и не получает изменения из D1.

Для входа нужен секрет `ADMIN_PASSWORD_HASH`. Создайте его командой `node scripts/admin-password.mjs` (ввод пароля скрыт, минимум 16 символов). Запишите полученный хеш в локальный `.dev.vars`:

```text
ADMIN_PASSWORD_HASH="полученный хеш"
```

`.dev.vars`, временные тестовые реквизиты и локальная база исключены из Git. Не размещайте их в публичной папке `dist/`.

## Подключение Cloudflare после локальной проверки

1. Создать репозиторий GitHub и загрузить исходники с `package-lock.json`. В репозиторий не входят `.preview/`, `dist/`, `.wrangler/`, `.dev.vars`, `node_modules/` и сгенерированный `cloudflare/pages.json`.
2. В Cloudflare создать D1 с именем `laveliya`. Вставить её настоящий `database_id` в `wrangler.jsonc` вместо нулевого шаблона. Создать Worker с именем `laveliya`.
3. Авторизоваться в Wrangler через `npx wrangler login`, затем выполнить `npx wrangler d1 migrations apply laveliya --remote`. Миграции отслеживаются D1; повторный запуск не перезаписывает сохранённые цены.
4. Создать собственный пароль с `node scripts/admin-password.mjs`. Передать полученный хеш как секрет Worker командой `npx wrangler secret put ADMIN_PASSWORD_HASH`. Секрет вводится в терминале, не в командной строке и не в Git.
5. Подключить GitHub-репозиторий в Cloudflare Workers → Settings → Builds. Build command: `npm run build`. Deploy command: `npx wrangler deploy`. Lockfile фиксирует зависимости.
6. До покупки домена оставить `SITE_URL` пустым и `INDEXABLE` равным `"false"`: сайт доступен через адрес Worker, но закрыт от индексации.
7. После подключения купленного домена задать `SITE_URL` как его полный HTTPS-адрес без завершающего слеша и `INDEXABLE` как `"true"` в `wrangler.jsonc`. Выполнить деплой. Тогда Worker выдаёт актуальные canonical, sitemap и robots.txt. Админка и API всегда закрыты от индексации.

Отдельный VPS или PHP-хостинг не требуется. Использование Cloudflare зависит от лимитов выбранного тарифа. Эта инструкция не означает, что облачный аккаунт, репозиторий или база уже созданы.

## Данные и безопасность

- В HTML каждой страницы подставляются актуальные данные из D1: цены, телефон, адрес, маршруты, заголовки и JSON-LD. Сохранённые изменения доступны при следующем открытии/обновлении страницы; HTML выдаётся с `Cache-Control: no-store`.
- Цены восьми услуг независимы; пометка «от» сохраняется. Телефон общий для звонков и WhatsApp.
- Адрес включает город, строку адреса и точку назначения. При переезде нужно изменить координаты; старый ID здания 2ГИС очищается при их редактировании. Ссылки проверки доступны в админке.
- Пароль проверяется только на Worker: PBKDF2-SHA256, уникальная соль, 100 000 итераций. Используйте длинный случайный пароль. Хеш хранится в секретах Cloudflare.
- Сессия действует 8 часов, cookie `HttpOnly`, `SameSite=Strict`, на HTTPS — `Secure`. Сессии отзываются при выходе. Для немедленного отзыва всех сессий после смены пароля выполните в D1 `DELETE FROM sessions;`.
- Изменения требуют действующей сессии, совпадающего Origin и CSRF-токена. Есть ограничения входа (10 попыток с адреса за 15 минут, 60 суммарно), ограничение размера запроса, валидация полей и параметризованные SQL-запросы.
- Версия записи предотвращает молчаливое затирание данных при одновременном редактировании. Данные сохраняются атомарно одним UPDATE.
- База должна быть доступна: при её отказе сайт возвращает 503, а не устаревшие цены. Перед запуском проверить восстановление D1 и экспорт резервной копии в аккаунте Cloudflare.

## Проверки

```sh
npm run build
npm test
node tests/integration.mjs
npx wrangler deploy --dry-run --outdir .preview/worker-build
```

Интеграционная проверка требует запущенный локальный Worker и локальный `.preview/admin-test-secret.json` с временным тестовым паролем. Она не обращается к облаку; временно меняет настройки, проверяет все страницы и восстанавливает исходные значения. Для собственного пароля этот файл создаётся только локально и никогда не коммитится.
